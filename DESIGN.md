# Waveform display

The user pinned XDJ-AZ fidelity. This is an Operate surface: four equally sized horizontal waveform lanes, no browser, transport pads, meters or decorative cards. First viewport: all four decks in 3–1–2–4 order, beat-aligned playhead rail, cue flags above the signal and saved-loop brackets below it. Configuration remains in the separate control window.

System sans typography supports installed-platform rendering; numeric data is tabular in purpose. Scale derives from lane height with a user multiplier, not a fixed 1080p canvas. Empty lanes show deck number and waiting state. Demo data is explicitly labelled synthetic.

Motion is playback-driven only. Markers retain exact track-time positions through zoom and tempo changes. A saved loop never implies it is currently engaged. Native controls retain keyboard focus and labels.
