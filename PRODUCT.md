# Rekordbox Wave

## Platform
Desktop: Windows and macOS (Python, Tk, SDL2/pygame).

## Users and purpose
A DJ using a DDJ-FLX10 wants four enlarged waveforms on a separate 15.6-inch 1920 × 1080 display. Rekordbox retains browsing and deck controls on the main display.

## Confirmed requirements
- Two or four decks; default four-row order 3, 1, 2, 4, configurable.
- XDJ-AZ waveform visual language, true three-band rendering, accurate beat grid, cues and loops.
- Persistent monitor binding and scalable layout across display sizes.
- Mixed sources, primarily exported USB media.
- Preserve currently supported Rekordbox versions. Existing live reader is Windows-specific, versions 7.2.2 and 7.2.14; macOS live memory support is unvalidated.

## Boundaries
The application displays playback; audio, browsing and performance controls stay in Rekordbox. Streaming analysis availability and native macOS live integration remain open technical constraints. Do not claim compatibility without testing.
